# SS-034 — Unvalidated deployer usage without caller authorization

- **Severity:** high
- **Confidence:** low
- **Category:** authorization

## Problem

`env.deployer()` allows a contract to deploy child contracts under its own
identity (`with_current_contract`) or another address (`with_address`), upload
new WASM bytecode (`upload_contract_wasm`), or upgrade its own executable code
(`update_current_contract_wasm`). If a public entry point invokes these methods
without a prior caller authorization check (`require_auth` or
`require_auth_for_args`), an unauthenticated caller can deploy unauthorized
contracts, exhaust deterministic salts, or replace contract code.

## How it is detected

In confirmed Soroban projects, the detector inspects each public contract entry
point (`pub fn` inside a `#[contractimpl]` block or module, including intra-file
helper functions up to a bounded call depth) for `env.deployer()` chains calling
`deploy`, `deploy_v2`, `update_current_contract_wasm`, or `upload_contract_wasm`.
A finding is reported when no `require_auth` or `require_auth_for_args` call
precedes the deployment or WASM registration call in the entry point or in its
called intra-file helpers.

## Limitations

- Analysis is intra-file; authorization enforced in a helper defined in another
  module or crate is not visible.
- `with_address(deployer, salt)` may rely on the host requiring authorization
  from `deployer` depending on how the address is constructed, or deployment may
  be intentionally permissionless in open factory contracts.

## False positives

- Open factory contracts that intentionally allow any user to deploy a child
  contract with a user-supplied salt and verified WASM hash.
- Entry points that delegate authorization to an external access-control helper
  in another file.

## Remediation

Authorize the caller or administrator before invoking `env.deployer()` deployment
or WASM registration methods, and validate the deployer identity or resulting
address where appropriate:

```rust
pub fn deploy_child(
    env: Env,
    admin: Address,
    salt: BytesN<32>,
    wasm_hash: BytesN<32>,
) -> Address {
    admin.require_auth();
    env.deployer().with_current_contract(salt).deploy_v2(wasm_hash, ())
}
```
