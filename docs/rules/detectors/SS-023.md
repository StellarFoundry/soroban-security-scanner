# SS-023 — Sensitive data published in contract event

- **Severity:** low
- **Confidence:** low
- **Category:** events

## Problem

A contract entry point publishes an event whose topic or payload references an
identifier associated with secret material (such as `secret`, `private_key`,
`password`, `mnemonic`, or `preimage`). Soroban contract events are public and
permanently recorded in ledger metadata, exposing any emitted secret to all
observers.

## How it is detected

Within a public `#[contractimpl]` entry point, the detector inspects
`env.events().publish(...)` arguments and flags calls that mention secret-like
identifiers.

## Limitations

- Name-based heuristic; cannot determine whether the value is already hashed or
  intentionally public (such as an atomic-swap HTLC preimage reveal).

## False positives

- HTLC contracts that intentionally publish a preimage to complete a swap.

## Remediation

Never emit raw secrets or private keys in `env.events().publish(...)`. Emit a
cryptographic commitment or an opaque identifier instead.
